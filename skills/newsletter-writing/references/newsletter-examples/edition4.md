Subject Line: Build Your AI Overview Gap Checker
Title: How to Run an AI Overview Gap Analysis

2025 marked a turning point for organic search. The rise of Google’s AI Overviews has led to a noticeable drop in traditional organic clicks.

Ahrefs’ latest study shows AI Overviews appearing on 21% of keywords, with informational searches driving nearly all of them.



Looking ahead to 2026, optimizing content to be referenced by AI Overviews will be key to sustaining organic visibility. 
But how do you uncover the gaps between what AI Overviews surface and what your content covers? Chris Long tackled this question in a recent LinkedIn post.

He prompted a ChatGPT agent to search Google, analyze the AI Overview, review his blog post, and then identify content gaps by highlighting what the article is missing to increase its chances of being referenced.



A compelling use case we felt was worth testing ourselves.
So we enabled agent mode on ChatGPT and used this prompt: 

1. Go to https://google.com and search for “what is A/B testing.” 
2. Analyze the complete Google AI Overview shown for this query. 
3. Read the blog post at https://cxl.com/blog/ab-testing-guide/ 
4. Identify content gaps between the AI Overview and the blog. 
5. Find content gaps between information included in the AI Overview that's not present on our blog.

Feel free to reuse this prompt and simply replace the search query and blog URL as needed.

After precisely 3 minutes, we got a pretty decent analysis.


The primary drawback is scalability. Running this for multiple blogs and queries means repeatedly re-prompting ChatGPT or waiting longer for a single, large batch to complete.

However, if there’s one thing we learned from the previous newsletter, it’s that building a Chrome extension is now easier than ever, even without prior coding knowledge.

So why not create something more intuitive: an AI-powered Chrome extension that activates when an AI Overview appears, scans the overview, prompts you to add your blog, and delivers a gap analysis in under 30 seconds?

Step #1: Go to ChatGPT and ask it to write the code

Similarly to what we did last time, we went to ChatGPT and wrote this prompt:


Build a Chrome extension. The extension should activate whenever a Google AI Overview appears on a search results page. When triggered, it should prompt the user to add a blog article URL.

After the URL is added, the extension should analyze the content shown in the AI Overview and compare it with the blog article. It should then perform a gap analysis, highlighting what information appears in the AI Overview but is missing from the blog, and suggest what to add to improve the chances of being referenced.

The extension should be powered by the ChatGPT API on the backend, have a clean and intuitive UI, and be easy to use.

At the end, provide a downloadable ZIP file that can be uploaded directly as a Chrome extension.

Step #2: Download the ZIP file generated by ChatGPT



Step #3: Open Chrome's Extension Manager

Go to chrome://extensions and enable “Developer mode” in the top-right corner. Then click “Load unpacked” and upload the unzipped extension folder.



If you run into an error, copy the error message into ChatGPT and ask it to fix the issue. Then repeat the process and upload the updated folder.

Step #4: Create your OpenAI Secret Key

Go to https://platform.openai.com/api-keys, create a secret key for the extension, and confirm that billing is configured so the API calls don’t fail.



Step #5: Setting up the extension

Open the Chrome extension from the toolbar and paste in your secret API key.


Step #6: Test it out

We went on Google and searched for: “What is A/B testing?”.

This activated our Chrome extension, which pulled in the AI Overview. We then added the blog URL for analysis.

Within 30 seconds, we were able to get a gap analysis. 



Feel free to build it yourself by following our steps, or download our extension and give it a try.


Please note that this is an experimental build, so you may encounter a few bugs. We’d love to hear any feedback or suggestions you have.

As AI Overviews increasingly shape what users see, the competitive edge will go to teams that systematically analyze what AI surfaces and close those gaps faster than everyone else.
