Building our own ai visibility tracker

In the meantime, we continued experimenting with n8n and realized something:
Building an AI visibility tracker is easier than you’d think, especially for tracking brand citations in Google AI Overviews and spotting competitor mentions.



Step #1: Add the list of queries you want to monitor into a spreadsheet, basically the searches where you want to check if your brand gets cited.


Step #2: Use the Split node in n8n to process the queries one by one.

Step #3: Use the searchapi.io node to run a Google search and extract the AI Overview.



Step #4: Document all the citations in a separate file, query by query.

Step #5: Feed that document into an AI agent with a structured prompt so it can analyze the data and generate a report.

“You are a structured data extraction engine.

You will receive AI Overview transcripts from multiple Google queries.

TASK:

1. Identify all brand names mentioned in each transcript.
2. Count how many times each brand appears per query.
3. Track how many times "CXL" appears (case-insensitive).
4. Build an aggregated brand count across all queries.
5. Map each brand to the queries where it appears.

Return EXACTLY this structure:

{
  "total_queries_analyzed": 0,
  "summary": {
    "total_unique_brands_across_all_queries": 0,
    "total_cxl_mentions": 0,
    "all_brand_mentions": {}
  },
  "queries": [
    {
      "query_text": "",
      "brands_mentioned": {},
      "cxl_mentions": 0
    }
  ],
  "brand_to_queries": {}
}”

What this report revealed

This report gave us a clear, data-backed view of our AI visibility across key informational queries.




Instead of guessing where we stand, it shows exactly where we’re invisible, who owns those conversations, and which topics represent immediate opportunity gaps if we want to increase our authority in AI Overviews.
