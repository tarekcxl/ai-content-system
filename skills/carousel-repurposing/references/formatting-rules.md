# Newsletter → Carousel Repurposing Rules

## Goal

Turn long-form newsletters into short, highly skimmable LinkedIn carousels.

Focus on:

* clarity
* readability
* one idea per slide
* short punchy copy

---

# Core Rules

## 1. One Idea Per Slide

Each slide should communicate a single concept only.

Avoid:

* long explanations
* multiple ideas
* dense paragraphs

---

## 2. Shorten Everything

Turn paragraphs into:

* short sentences
* bullets
* stacked lines

Example:

Newsletter:
"GitHub stores workflows, prompts, and AI systems."

Carousel:
GitHub stores:

* Workflows
* Prompts
* AI systems

---

## 3. Use Simple Formatting Patterns

### Definitions

Use:

* Repository = project folder
* Commit = saved change

### Frameworks

Use short bullet lists.

### Transition Slides

Short section headers:

* “How Claude Code repos work”
* “Key repo components”

---

# Writing Style

Keep copy:

* concise
* visual
* easy to scan
* strategic

Avoid:

* filler
* long transitions
* hypey language

---

# Compression Rule

The newsletter contains depth.

The carousel only keeps:

* the core insight
* strongest examples
* clearest phrasing

---

# Ideal Carousel Flow

1. Hook
2. Why it matters
3. Core concepts
4. Definitions/frameworks
5. Workflow explanation
6. Final takeaway

---

# Final Slide

End with:

* a strong conclusion
* a future-facing statement
* a simple summary

Example:
“GitHub is becoming an operating system for modern marketing workflows.”
