# Carousel Repurposing

Transform content into highly engaging carousel formats optimized for retention, readability, and shares.

---

## What this skill does

Use this skill to:
- create LinkedIn carousels
- create Instagram carousels
- turn long-form content into slides
- improve swipe retention
- structure educational content visually
- generate carousel captions
- optimize for saves and shares

---

## Core Principles

- one idea per slide
- clarity beats complexity
- strong hooks increase swipe-through rate
- short copy performs better
- pacing matters
- visual rhythm improves retention
- each slide should create momentum toward the next

---

## Carousel Structure

Recommended structure:

1. Hook slide
2. Problem/context
3. Key insight
4. Supporting insight
5. Examples or proof
6. Summary
7. CTA

---

## Hook Best Practices

Good hooks:
- create curiosity
- challenge assumptions
- promise value
- create tension
- highlight pain points
- use specificity

Examples:
- “Most marketers are doing this wrong.”
- “This changed our SEO strategy completely.”
- “Nobody talks about this growth tactic.”

---

## Caption Optimization

Always include:
- an engaging opening line
- additional context or insight
- conversational formatting
- CTA when relevant

The caption should:
- reinforce the carousel
- encourage comments/saves/shares
- provide extra context not shown in the slides
